# Feature audit — Al-Madina Jewellers Android app

Audited 16 November 2026 against `master` at `92ee97c` (release 5, version 2.1).

**What "Implemented" means here:** the code was found and read, and the
feature runs from the app's own bundled screens (`mobile/app/src/`). It does
not mean a document or the old listing says so. Where it mattered, the screen
was also run against live data (`bun run dev` in `mobile/`) and looked at.

- **Implemented** — in the app's own screens, working end to end.
- **Partial** — part of it is in the app, or it exists only on the website the
  app opens in its WebView (the drawer's _Our Website_). The note says which.
- **Missing** — not in the code.

The app is two halves: its own screens, bundled in the APK and working offline,
and the live website, opened in the same WebView for everything else
(`mobile/capacitor.config.ts`). Only the first half counts as Implemented.

## What this changes in the listing

The old full description (in `mobile/play-store/README.md`) promised two things
the app does not do on its own screens — an estimator under _Sell your gold_
and sharing the rate as a picture — and called the calculator something it is
not. [`PLAY_STORE_METADATA.md`](PLAY_STORE_METADATA.md) and the screenshot
captions in `mobile/play-store/captions.json` use only the Implemented rows.
